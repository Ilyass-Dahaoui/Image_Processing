# Image Processing

This repository contains several foundational image processing tasks implemented in Python, mainly using the OpenCV and NumPy libraries. It serves as an educational resource for understanding core image manipulation techniques.

##  Project Structure

- `Color_Space_Transformation.ipynb`:  
  Notebook demonstrating how to convert images between various color spaces (RGB, HSV, Grayscale, etc.).

- `Filtering.ipynb`:  
  Shows how to apply different types of filters, including smoothing (blurring), sharpening, and edge detection using kernels.

- `Histogram_Equalization.ipynb`:  
  Implements histogram equalization for contrast enhancement on grayscale and color images.

- `Thresholding.ipynb`:  
  Demonstrates global and adaptive thresholding techniques for image segmentation.

- `Morphological_Operations.ipynb`:  
  Explains and applies operations like erosion, dilation, opening, and closing on binary images.
